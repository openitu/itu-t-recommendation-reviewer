# Pre-approval quality checklist

## Annex D checklist (Author's guide) — reproduce as the report's §5 table

Before a draft is proposed for approval/consent/determination, the rapporteur must confirm the draft:

1. has been thoroughly reviewed for technical accuracy *(mark N/A-for-this-review; note it is the rapporteur's duty)*;
2. is technically sound with **as few options as feasible** *(count optional features/modes; many options = flag)*;
3. does not conflict with the content of an already approved Recommendation *(check any the user names; otherwise mark "not verified — requires SG knowledge")*;
4. does **not contain case studies within the normative part**;
5. has only **short illustrative examples**, if necessary, in the normative part;
6. follows the author's guidelines including ITU-T templates;
7. has been spell-checked and is grammatically correct;
8. contains definitions developed after consulting the ITU-T Terms and Definitions database and following SCV guidance;
9. has **all acronyms, including those in figures and tables, correctly spelled out**;
10. has the normative part **making use of all references in clause 2**;
11. has all clause-2 references **qualified per ITU-T A.5** (for non-ISO/IEC SDO documents).

Grade each row pass / fail / N-A with one line of evidence (location or count).

## Additional automated-style sweeps worth running on the text

- Search "may not" → replace with "need not" (mandatory in common texts; good practice in all).
- Search "shall" / "must" inside Summary, Introduction, Scope, NOTEs, appendices → violations.
- Search "page" in cross-references → should be clause/figure/table numbers.
- Search quotation-marked novel terms and all-caps words not in clause 4 → capitalization/conventions issues.
- Verify every "[" citation tag resolves to a clause-2 or Bibliography entry, and vice versa.
- Verify every "Figure n" / "Table n" mentioned exists, and every existing figure/table is mentioned.
- Check keywords line: alphabetical, comma-separated.
- Check abbreviations list: alphabetical; each acronym actually used in the text; each acronym in the text present in the list.

## Process-context checks (ITU-T A.1) — report under "next steps" only when relevant

- Draft Recs for consent/determination: separate TDs, ≥6 weeks before the parent meeting; TD titled "Draft new Recommendation ITU-T X.x: <title>" (one document per Recommendation).
- New work item documented with the A.1 Annex A template.
- IPR question asked and recorded; software copyright form filed when copyrighted software is submitted.
- Contribution deadlines: 12 calendar days minimum; 2 months for translation.
- Rapporteur report format per A.1 Appendix I when the input is a rapporteur report rather than a draft Rec.
